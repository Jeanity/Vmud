## Files used

| File | Used for |
| --- | --- |
| `grass.png` | field, forest, hills |
| `grassalt.png` | terrain variation |
| `dirt.png` | roads, city cobbles, desert |
| `dirt2.png` | interiors, mountain, swamp |

| `treetop.png`, `trunk.png` | tree decoration |
